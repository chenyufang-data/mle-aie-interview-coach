Coding drills run in the local app: a code box next to LeetCode, your code run on your own machine, and a hint ladder that climbs from a clarifying question to one step of pseudocode - never the whole answer.

  1. Clone the repository and install it (Python 3.12).
  2. Sign in to Claude Code or Codex, or put an API key in .env.
  3. Run python server.py and open http://127.0.0.1:8000/coding.html.
