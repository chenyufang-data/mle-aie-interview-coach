# rag_exp - real interview-experience question bank

The third question bank (plan section 7b): questions actually asked in
recent MLE/AIE interviews, hand-collected (interview-experience posts and
the user's own interview log under `data/interview_exp/`), rephrased into
interviewer English with grading rubrics generated by the Claude teacher.

Unlike `rag_ml/` and `rag_ai/`, the bank itself is **private**: chunks
carry company names, rounds, and question provenance from real interview
processes, so `all_chunks.jsonl` is gitignored and only this README is
tracked. Deployments mount the bank from private storage.

Build / update it locally:

    .venv\Scripts\python grader\ingest_questions.py                     # free dry run + cost estimate
    .venv\Scripts\python grader\ingest_questions.py --generate --confirm  # paid teacher run

The ingest normalizes and dedupes the raw sources (lexically, by HR-screen
intent, and against the course banks), then generates one rubric chunk per
surviving question in the same `id / interview / metadata` schema the app
already serves. Re-runs are idempotent - existing chunk ids are skipped.
